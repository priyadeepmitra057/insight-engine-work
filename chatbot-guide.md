# Chatbot Frontend Guide

This guide explains how to integrate the Insight Engine Chatbot into your frontend application.

## High-Level Architecture & Message Flow

The chatbot feature is designed to interact with the backend context generated by an analysis run. The flow is completely stateless on the frontend and relies on standard REST calls.

**Note: The chatbot currently generates responses synchronously. It does NOT support streaming.** You will receive the entire response in a single JSON payload.

### The Standard Flow

1. **Upload & Analyze**: The user uploads a CSV statement via `POST /api/v1/insights/analyze`. The backend automatically saves the "context" for this user securely.
2. **Start Session**: The frontend calls `POST /api/v1/chat/start`. The backend links this session to the most recent context and returns a `session_id`.
3. **Exchange Messages**: The frontend sends messages via `POST /api/v1/chat/message`, passing the `session_id`. The backend responds with the complete `answer`.
4. **End Session**: (Optional) The frontend can explicitly delete the session using `DELETE /api/v1/chat/session/{session_id}`. Sessions expire naturally on the backend.

### Important Constraints
* **Authentication:** Every request must include the `X-Merchant-Token` header.
* **Turn Limits:** A session has a maximum number of turns (messages exchanged). The response from `/start` and `/message` includes a `turns_remaining` integer.
* **Message Limits:** User messages are capped at 512 characters.
* **Single Thread:** The backend strictly processes one message at a time per session. If you send a message while the previous one is still processing, you will receive a `429 Too Many Requests` error.

## Minimal React Reference Component

Here is a simple React component that implements the entire chatbot flow. It assumes the user has already completed the analysis step.

```jsx
import React, { useState } from 'react';

const MERCHANT_TOKEN = "user-auth-token-123";

export default function Chatbot() {
  const [sessionId, setSessionId] = useState(null);
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);
  const [turnsRemaining, setTurnsRemaining] = useState(null);

  const startChat = async () => {
    setLoading(true);
    setError(null);
    try {
      const res = await fetch('/api/v1/chat/start', {
        method: 'POST',
        headers: {
          'X-Merchant-Token': MERCHANT_TOKEN,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({}) // Uses most recent analysis
      });

      const data = await res.json();
      if (!res.ok) throw new Error(data.message || 'Failed to start chat');

      setSessionId(data.session_id);
      setTurnsRemaining(data.turns_remaining);
      setMessages([{ role: 'system', content: 'Chat started. How can I help?' }]);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  const sendMessage = async (e) => {
    e.preventDefault();
    if (!input.trim() || !sessionId || loading) return;

    const userMessage = input;
    setInput('');
    setMessages(prev => [...prev, { role: 'user', content: userMessage }]);
    setLoading(true);
    setError(null);

    try {
      const res = await fetch('/api/v1/chat/message', {
        method: 'POST',
        headers: {
          'X-Merchant-Token': MERCHANT_TOKEN,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          session_id: sessionId,
          message: userMessage
        })
      });

      const data = await res.json();
      if (!res.ok) throw new Error(data.message || 'Failed to send message');

      setMessages(prev => [...prev, { role: 'assistant', content: data.answer }]);
      setTurnsRemaining(data.turns_remaining);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };

  const deleteSession = async () => {
    if (!sessionId) return;
    try {
      await fetch(`/api/v1/chat/session/${sessionId}`, {
        method: 'DELETE',
        headers: { 'X-Merchant-Token': MERCHANT_TOKEN }
      });
      setSessionId(null);
      setMessages([]);
    } catch (err) {
      console.error('Error deleting session:', err);
    }
  };

  if (!sessionId) {
    return (
      <div style={{ maxWidth: 400, margin: 'auto', padding: 20 }}>
        <button onClick={startChat} disabled={loading}>
          {loading ? 'Starting...' : 'Start Chat'}
        </button>
        {error && <p style={{ color: 'red' }}>{error}</p>}
      </div>
    );
  }

  return (
    <div style={{ maxWidth: 400, margin: 'auto', padding: 20, border: '1px solid #ccc' }}>
      <div style={{ height: 300, overflowY: 'auto', marginBottom: 10 }}>
        {messages.map((msg, idx) => (
          <div key={idx} style={{ textAlign: msg.role === 'user' ? 'right' : 'left', margin: '5px 0' }}>
            <strong>{msg.role === 'user' ? 'You' : 'AI'}:</strong> {msg.content}
          </div>
        ))}
        {loading && <div style={{ textAlign: 'left', color: 'gray' }}>AI is typing...</div>}
      </div>

      {turnsRemaining !== null && (
        <div style={{ fontSize: '12px', color: '#666', marginBottom: '10px' }}>
          Turns remaining: {turnsRemaining}
        </div>
      )}

      {error && <p style={{ color: 'red', fontSize: '12px' }}>{error}</p>}

      <form onSubmit={sendMessage} style={{ display: 'flex' }}>
        <input
          value={input}
          onChange={e => setInput(e.target.value)}
          disabled={loading || turnsRemaining === 0}
          style={{ flexGrow: 1, marginRight: 5 }}
          placeholder="Ask a question..."
          maxLength={512}
        />
        <button type="submit" disabled={loading || turnsRemaining === 0}>Send</button>
      </form>

      <button onClick={deleteSession} style={{ marginTop: 10, color: 'red' }}>End Chat</button>
    </div>
  );
}
```
